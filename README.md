## 🏠 Homelab
 
A self-managed server environment where I run 25+ containerized services and handle everything from configuration to monitoring myself:
 
- **Observability** — Prometheus, Grafana and Loki for metrics, dashboards and centralized logging
- **Git & CI/CD** — self-hosted Gitea with automated build and deploy pipelines
- **Mail server** — self-hosted on a VPS, including SPF, DKIM and DMARC setup
- **Automation** — Docker Compose and Ansible for reproducible, version-controlled deployments
